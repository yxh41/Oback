## 胶囊特效优化（feat/navbar-coordination，commit f53d8be）
- 用户反馈：胶囊风格里的「流光渐变」「霓虹」太生硬。两特效仅在 feat 分支 ObackManager.m 的 ObackEdgeIndicator init switch 里。
- **流光渐变（ObackCapsuleEffectGradient=3）生硬根因**：旧版同时动画 `startPoint`(0→1) 与 `endPoint`(1→0) 并 `autoreverses=YES` → 高亮带扫过去又硬倒回。改为 **2 倍宽渐变层（含两个相同周期）+ 单向平移一个周期(w)**，`fromValue=0→toValue=-w`、linear、无限循环；平移一个周期后首尾完全一致 → 无缝连续流动，无回弹/跳变。设 `self.layer.masksToBounds=YES` 裁剪到圆角（`transform.translation.x` 平移，`removeAnimationForKey` 同步停）。
- **霓虹（ObackCapsuleEffectNeon=2）生硬根因**：2pt 纯色硬描边 + 恒定强晕，像贴纸。改为 **近白青亮核(1.5pt) + 更大半径(22)半透明柔晕 + shadowOpacity 0.55~0.95 ease 微呼吸脉冲(2.6s autoreverse)**，模拟真实灯管明灭。`stopEffectAnimations` 同步 `removeAnimationForKey:@"obNeonPulse"` 防淡出残留。
- MRC 合规（无 __weak），无旧 obFlowStart/obFlowEnd 残留。已 push `f53d8be`。
- 注：此改动在 feat 分支，不在 main；用户装 feat 分支构建才会看到效果。待真机视觉验证自然度。
