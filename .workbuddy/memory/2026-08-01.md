## 修复 ⑪ 阴影「没有渐隐的变化」（commit de704fb，CI 出 `0.1.0+de704fb`）
- **现象（用户实测）**：左/右缘拖动返回时，阴影浓度恒定、不随进度衰减（即「没有渐隐的变化」）。
- **根因**：⑨ 的阴影渐隐依赖 `UIViewPropertyAnimator` 手动 scrub(`fractionComplete`) 时对 CALayer `shadowOpacity` 的逐帧插值。但真机上**手动 scrub 阶段 UIViewPropertyAnimator 对 CALayer 阴影属性插值不可靠**——CA 在 animator block 跑完捕获的目标(opacity=0)与起始(base)之间，暂停 scrub 时并不逐帧把该 layer 属性插值呈现，导致拖动全程 shadowOpacity 停在原值（被暂停态 CA 动画的 presentation 值"按住"）。
- **修复（去依赖 CA 插值，确定性显式驱动）**：
  1. `interruptibleAnimatorForTransition:` 的 `addAnimations` block **只驱动 transform**（UIView 属性，scrub 可靠），把阴影从 animator block 剥离 → 暂停态不再有 CA 动画占位盖住显式赋值。
  2. `updateWithPercent:` 内按 percent 用 `CATransaction(disableActions)` **即刻**落 `shadowOpacity = base*(1-percent)`，拖动零延迟跟手（base=shadowEnabled?shadowOpacity:0）。
  3. `forceFinishIfNeeded` 取消回弹时阴影随页面滑回一同淡出到 0（原来 `OBApplyParallax(0)` 把阴影动画回满值、再于 completion 瞬清零 → 突兀 pop），提交时仍由 `OBApplyParallax(1)` 置 0。
- **不受影响的部分**：transform 平移/缩放仍靠 animator scrub（可靠）；松手收尾走标准 UIView 动画（CATransaction 对阴影属性插值可靠）；`applyShadowTo:` 的 color/offset/radius 一次性设定不变。
- **待真机验证**：安全名单内 App 左/右缘拖动 → 阴影随拖动实时变淡（不再恒定）、拖到底完全消失露出上一页；松手提交无残留、取消平滑回弹且阴影淡出无 pop；调 shadowOffset/shadowRadius 滑块深浅/弥散实时生效。
